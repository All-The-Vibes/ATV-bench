## 2. HIGH '.gitattributes does not protect the contributor' — REFUTED

Documented flow is fork -> clone (docs/COMMUNITY_LEAGUE.md:13). A clone inherits
.gitattributes, so -text applies. Empirically, clone + core.autocrlf=true:
  committed blob: def move(s):\r\n    return "up"\r\n   <- CRLF PRESERVED
The failing scenario needs a checkout with no .gitattributes, which the real
submission flow does not produce.
